# 予約のルール

承認済みの記事を1〜3本選び、日付を指定すると時刻が自動で決まります。無料・200円の組み合わせ制限はありません。公開済み・予約済み・処理中・公開前確認済み・要確認の枠を合わせ、日本時間で1日3本までです。

時刻は10–12時、15–18時、19–22時の空き枠から決め、公開済みや予約済みの記事との間隔を2時間以上確保します。経過した時間枠に予約せず、日付を勝手に翌日へ移しません。画面では今後60日の空き枠を表示し、満枠の日と、選んだ本数を配置できない日は選択できません。

1本・2本の予約後にも、空き枠があれば同日に追加できます。予約を止めると空き枠へ戻ります。日付を変更する場合も、時刻は手入力せず再び自動決定します。公開許可と投稿処理の稼働が必要です。

予約・日付変更の書き込みは、承認版、空き枠、時間間隔を1つのSQL文で再確認し、全件成立する場合だけ反映します。同時操作で4本になったり、選んだ記事の一部だけ予約されないようにします。公開済み結果の照合は、件数制限よりも事実の反映を優先します。
