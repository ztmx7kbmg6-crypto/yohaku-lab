# 予約のルール

記事を開いて本文・画像・価格を確認し、「承認して自動予約」を押すと、その版の公開許可を記録して次の空き枠へ追加します。日付は最も早い空き枠の日、時刻はその日の最初に空いている時間帯の中から自動で決定します。

日本時間で、公開済みを含め1日あたり無料1本・200円2本までです。料金区分ごとに枠を確保します。同じ料金の枠が埋まった場合は次に空いている日へ回ります。1本でも予約できます。時間帯は10–12時、15–18時、19–22時です。記事の間隔は2時間以上あけます。

「予定」から予約の取り消しと日付の変更ができます。取り消した記事は承認済みへ戻り、空いた枠は次の承認で使えます。本文や画像を修正すると承認・公開許可・予約が失効します。投稿処理の全体停止中でも予約は保存され、公開には処理の再開が必要です。

同時に承認しても料金別の上限を守れるよう、対象の版、枠、時刻を更新時にも確認します。公開済みの照合は、公開の事実を正しく記録します。
